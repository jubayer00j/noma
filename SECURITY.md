# Security Policy

## Overview

Noma is an actively developed, offline-first note-taking application for Web, PWA, and Android. The security of our application and user data is very important to us.

## Reporting a Security Vulnerability

If you suspect or discover a security vulnerability in Noma, **please do NOT disclose it publicly** through public GitHub Issues, discussions, or social media.

Instead, please report the vulnerability privately to the maintainer via email:

- **Security Contact Email:** [dev.jubayer00j@gmail.com](mailto:dev.jubayer00j@gmail.com)

To help us better understand and address the issue, please include as much detail as possible in your report:

- **Description:** A clear overview of the issue and potential risk.
- **Affected Version/Commit:** The version, tag, or commit hash where the vulnerability was identified (if known).
- **Reproduction Steps:** Step-by-step instructions or proof-of-concept code to reproduce the issue.
- **Impact:** An assessment of the potential impact and attack vector.
- **Evidence:** Relevant logs, screenshots, or code snippets, if available.

## Non-Security Bugs & Feature Requests

For non-security bugs, general technical questions, and feature requests, please use the public [GitHub Issues](https://github.com/jubayer00j/noma/issues) or the in-app Contact & Feedback channel.
